# Changelog

All notable changes to the `buyback-skill` repository will be documented in this file.

## [1.0.0] - 2026-11-11

### Initial Release
- **Core Architecture:** Built standardized deep-dive workflow matching `dividend-skill` design patterns.
- **100-Point Scoring Model:** Comprehensive 5-filter evaluation framework (Premium, Retail AR, Health, Promoter Intent, Valuation).
- **SEBI Retail Quota Mechanics:** Exact calculation of the 15% Small Shareholder reservation bucket (< ₹2 Lakhs).
- **3-Scenario Arbitrage Modeling:** Formalized Bull (0% dip), Base (6% dip), and Bear (14% correction) scenario tables with break-even acceptance ratio formulas.
- **Finance Act 2024 Taxation:** Integrated Section 2(22)(f) deemed dividend taxation and allowable capital loss (STCL) setoff models for post-Oct 1, 2024 buybacks.
- **Single-File Prompt Edition:** Packaged `buyback-skill-full-prompt.md` for seamless single-prompt execution across any AI platform.
- **Reference Suite:** Authored `depth-standard.md`, `research-checklist.md`, `scoring-model.md`, `arbitrage-and-scenarios.md`, `tax-and-costs.md`, and `report-template.md`.
